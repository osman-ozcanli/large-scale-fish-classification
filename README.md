# Large Scale Fish Classification

CNN ve Transfer Learning (VGG16) ile büyük ölçekli balık türü sınıflandırması.

**Dataset:** [Large Scale Fish Dataset](https://www.kaggle.com/datasets/crowww/a-large-scale-fish-dataset) — Kaggle, orijinal sahiplerine aittir.

## Kullanılan Yöntemler
- Custom CNN
- VGG16 Transfer Learning

## Sonuçlar
Model hem macro avg hem de weighted avgde 0.94luk basari orani yakalamistir. Sonuclar modelin hala ogrenmeye acik oldugunu gostermistir.
